# 걱정 디버거

걱정을 적고 정리하는 작은 웹앱입니다.

## 무엇을 할 수 있나요?

- 걱정을 적을 수 있어요.
- 걱정을 `실행`, `보류`, `기록`, `내려놓기`로 나눌 수 있어요.
- 끝난 걱정은 `완료`로 표시할 수 있어요.
- 내 기록을 파일로 저장하거나 다시 불러올 수 있어요.
- 문의/개선사항은 Google Form으로 보낼 수 있어요.

## 실행 방법

```bash
npm install
npm run dev
```

## 파일 역할

- `src/WorryDebuggerApp.tsx`: 앱의 큰 틀을 연결합니다.
- `src/hooks/useWorries.ts`: 걱정 추가, 삭제, 완료 같은 일을 처리합니다.
- `src/lib/worryStorage.ts`: 브라우저 저장소에 걱정을 저장하고 읽습니다.
- `src/features/worries/components`: 화면에 보이는 조각들입니다.
- `src/utils/worryFilters.ts`: 검색, 분류, 숫자 계산을 합니다.

## 지금 구조는 어떤 구조인가요?

이 프로젝트는 React + TypeScript에서 자주 쓰는 구조입니다.

- `features`: 한 가지 기능과 관련된 화면을 모아둡니다.
- `hooks`: 화면에서 쓰는 상태와 동작을 모아둡니다.
- `lib`: 저장소처럼 기술적인 일을 맡습니다.
- `utils`: 계산이나 변환처럼 작고 반복되는 일을 맡습니다.
- `types.ts`: 여러 파일이 같이 쓰는 타입을 모아둡니다.

쉽게 말하면, 화면은 화면대로 두고, 계산은 계산대로 두고, 저장은 저장대로 나눈 구조입니다.
그래서 파일을 찾기 쉽고, 나중에 기능이 커져도 고치기 편합니다.
